# Qualification Boundary

`A01-CODE-QUAL-001` is not complete when the scaffold compiles. It is complete only when the exact benchmark package is sealed, the native A-01 run executes under the hard 30-minute boundary, the frozen artifact is evaluated post-window, and immutable evidence is preserved.

Scaffold validation proves only that the harness itself is syntactically executable and non-vacuous. It is not evidence of A-01 coding capability.
