## 3. Fresh research method

The benchmark prioritized sources capable of changing foundation design rather than collecting generic EdTech feature lists.

Evidence hierarchy used:

1. current public-sector / standards / measurement authorities;
2. 2025-2026 systematic reviews and meta-analyses;
3. recent randomized controlled evidence where it tests a material design proposition;
4. current interoperability specifications and implementation guidance.

The review deliberately distinguishes:

- **task performance** from learning;
- **immediate learning** from delayed retention;
- **same-task success** from transfer;
- **learner self-report** from competence;
- **activity telemetry** from evidence interpretation;
- **interoperability format** from canonical truth;
- **AI/model confidence** from measurement validity;
- **software qualification** from instructional effectiveness.

## 5. Research findings that materially change the rebuild

### 5.1 The system must optimize learning, not just task success

OECD's 2026 Digital Education Outlook draws the exact distinction the current Learning rebuild needs: GenAI can improve task output while producing little or no real learning when it replaces cognitive effort; educational GenAI is more promising when built around explicit pedagogy such as questioning, nudging and strategy shifts.

The current System Master evidence/mastery fences already prevent a completed task or score from automatically becoming mastery. The missing step is to apply the same rule to **adaptive policy and tutoring behavior**.

Foundation consequence:

- short-term correctness/completion cannot be the sole adaptive objective;
- AI help level must be part of interpretation context when it changes what the evidence means;
- policies must support scaffold fading and independent performance;
- retention/transfer/independence must have explicit evidence paths.

### 5.2 The learner model must be explicit, uncertainty-aware and non-authoritative over its sources

The current architecture has many correct learner-state objects but no single frozen architectural projection that answers: **what does the system currently believe/know about this learner, which parts were observed, which were inferred, how uncertain are they, and as of what version?**

The 2025 systematic learner-model review identifies learner modelling as a distinct component of adaptive systems and calls out interpretability, privacy/sovereignty, interoperability and controlled evaluation. The 2025 adaptive-learning review likewise shows that adaptive systems commonly lean heavily on performance traces.

Foundation consequence:

Add a `LearnerModelProjection`-class responsibility as a **read/projection synthesis**, not a second writer. Every field must resolve to canonical owner state and carry:

- observed / inferred / unknown classification;
- source/provenance reference;
- as-of/version;
- policy/model version for inferred values;
- uncertainty/coverage;
- staleness/contradiction standing.

### 5.3 Self-confidence is useful but too narrow

S07 correctly says confidence is not competence and cannot change mastery by itself. That remains valid.

But fresh SRL evidence shows that effective independent learning involves planning, monitoring and evaluating learning, plus regulation of motivation and strategy. A 2026 systematic review specifically warns that personalized systems can perform regulation for the learner and thereby fail to build the learner's own regulatory competence.

Foundation consequence:

- keep `SelfConfidenceObservation`;
- stop treating it as the entire learner self-regulation foundation;
- add explicit planning/monitoring/evaluation/strategy-use support;
- allow bounded learner-declared motivation/effort/task-value/confusion context only as non-dispositive, non-diagnostic context;
- do not admit automatic emotion/mental-state inference from raw telemetry as canonical learner truth.

### 5.4 AI tutoring needs a versioned pedagogy contract

A 2025 randomized controlled trial in undergraduate physics found greater learning gains and lower time-on-task with an AI tutor than the compared active-learning classes, but the system was deliberately designed with research-based pedagogy, scaffolding and targeted prompting. A 2025 meta-analysis of digital scaffolding prompts likewise found positive average effects but large design/context dependence.

Foundation consequence:

Curriculum's existing `InstructionalPolicyVersion` is the correct owner, but it must be expanded to cover at minimum:

- questioning before answer substitution where policy calls for productive retrieval;
- hint hierarchy;
- worked examples and completion problems;
- self-explanation prompts;
- feedback level/timing;
- scaffolding and fading;
- cognitive-load bounds/chunking;
- when direct answers are appropriate;
- learner-control/override rules;
- assistance level that must be preserved with evidence;
- safe fallback when the tutor/model is untrusted/unavailable.

Learning chooses **when** an instructional action is eligible from learner state; Curriculum owns **what the instructional strategy means**. That owner split remains.

### 5.5 Retention, transfer and independence need operational evidence plans

The current S05 state model already distinguishes demonstrated, retained, transfer-demonstrated and mastered states. That is a strong semantic start.

The rebuild must make the evidence plans executable and auditable:

- retention requires delayed evidence under a versioned interval/context policy;
- transfer requires materially different application conditions, not repeated near-identical items;
- AI-assisted evidence must preserve the assistance condition when it matters;
- independent verification should be available where the intended construct is independent performance;
- accommodations/assistive technologies must not be treated as illegitimate assistance when they are part of the authorized assessment construct.

### 5.6 Responsible AI measurement requires more than a calibration flag

The shared `ModelNotCalibrated` dependency is a sound owner boundary. It is not yet a complete responsible-measurement contract.

ETS's 2025 responsible-AI framework emphasizes fairness and bias mitigation, privacy/security, transparency/explainability, accountability, educational impact/integrity, representative data and ongoing analysis.

Foundation consequence:

Learning owns the intended educational use and consequence policy; shared Assurance/AI Safety owns generic model-governance machinery. Consequential model/scorer use must bind:

- exact model/scorer/rubric version;
- intended use and prohibited use;
- calibration/validation receipt;
- representative evaluation scope;
- subgroup/fairness checks as applicable;
- drift/revalidation standing;
- explanation/uncertainty;
- human review/escalation requirements;
- failure/degrade behavior.

### 5.7 Standards should be adapters, not owners

Current standards offer real value without requiring a semantic rewrite:

- **CASE 1.1** — competency/standards/framework/association exchange;
- **QTI 3** — assessment content/results interchange with modern accessibility/accommodation support;
- **Caliper Analytics** — common event vocabulary for learning activity/usage;
- **CLR 2.0** — portable verifiable learner-record/achievement exchange;
- **WCAG 2.2** — current W3C-recommended accessibility baseline for web content.

Foundation consequence:

Add an integration-adapter responsibility. The adapters map to/from canonical System Master owners. They cannot:

- create mastery;
- create psychometric validity;
- create competency equivalence;
- create learner identity authority;
- create eligibility/certification;
- override rights/privacy/authorization.

## 7. Hard no-go decisions

The research does **not** authorize any of these shortcuts:

- task completed -> learned;
- answer quality -> mastery;
- high AI/model confidence -> mastery;
- high self-confidence -> mastery;
- repeated same-item success -> transfer;
- elapsed time -> retention;
- Caliper event -> evidence admission;
- CASE association/model similarity -> canonical competency equivalence;
- QTI conformance -> psychometric validity;
- CLR/Open Badge/credential payload -> Learning certification authority;
- chat/webhook/provider metadata -> learner semantic authority;
- generic job/scheduler success -> Learning semantic success;
- automatic inferred emotion/mental-state telemetry -> canonical learner truth;
- demographic/sensitive-attribute personalization by default;
- historical software PASS -> current changed-subject qualification;
- software qualification -> instructional effectiveness.
