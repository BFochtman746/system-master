## 5. Collision-elimination rules

These rules are mandatory during the 110/110/26 row adjudication.

1. **Learner identity vs platform principal** — Learning owns learner educational identity/profile and educational state; Core owns authentication/principal/delegation identity. A mapping may link them but neither store substitutes for the other.
2. **Curriculum/source file vs document mechanics** — Learning owns curriculum/source semantic identity, currentness, coverage and admissibility; Documents owns generic file/OCR/render/export mechanics; Core may own custody transport.
3. **Assessment artifact vs document artifact** — Learning owns item/rubric/scoring/evidence meaning; Documents owns file-format mechanics.
4. **Learning evidence vs generic evidence substrate** — Learning owns what evidence means for mastery/progress/retention/transfer; Core owns generic evidence transport/provenance mechanics. Infrastructure success never becomes Learning PASS.
5. **Learning goal vs product user intent** — Learning owns instructional goal state inside an admitted Learning program; Core/System Master owns product-level governed user intent. Learning cannot expand user authority.
6. **Learning workflow vs generic execution runtime** — Learning owns pedagogical state transitions and next-action validity; Core owns generic job/attempt/queue/lease/retry mechanics.
7. **Mastery/adaptation vs model gateway** — Learning owns model semantics, thresholds and acceptance criteria; Core may execute/model-route, but a model response cannot directly become mastery.
8. **Learning persistence vs database platform** — Learning owns canonical semantic schema/version/invariants; Core owns database engine/custody/recovery mechanics unless a later explicit architecture decision says otherwise.
9. **Learning telemetry vs learning truth** — telemetry is projection/evidence input, never canonical mastery/progress truth by itself.
10. **Learning qualification vs Programming/Core test mechanics** — shared tooling may run tests; Learning owns domain-specific correctness predicates and the limits of claims.
11. **Learning content about Book/Programming/etc. vs target-system state** — teaching or assessing a domain never grants Learning mutation authority over that domain's canonical state.
12. **Artifact success vs educational success** — rendered/exported/materialized artifacts do not prove curriculum completeness, mastery, retention, transfer, effectiveness or certification.
