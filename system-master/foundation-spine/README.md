# System Master Foundation & Spine

Status: CANONICAL DOCUMENTATION SET v1
Date: 2026-09-11

This directory is the sole current human-facing architecture documentation authority for the System Master Foundation & Spine.

## Reset rule

The Foundation & Spine documentation was rebuilt from first principles because the prior documentation accumulated multiple generations, overlapping authorities, repair-era labels and historical assumptions. Prior prose is not normative merely because it existed first.

The new design is derived from three evidence classes:
1. current implementation and current repository evidence;
2. archival implementation, audits, failures and recovered design work;
3. current external engineering and safety research.

When these disagree, the design that best satisfies the product goal, safety, correctness, durability, clarity and non-duplication wins. Historical labels are preserved only when still useful.

## What this reset does not delete

This reset is documentation-only. It does not delete or invalidate source code, tests, routes, logs, workflows, schemas, patches, receipts, qualification evidence, reconciliation records, runtime data, artifacts, source manifests or recovery evidence. Those remain evidence about what has been built and what has happened.
