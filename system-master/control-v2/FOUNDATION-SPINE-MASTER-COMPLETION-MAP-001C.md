## Interpretation rules

1. `SUPERSEDED_TOPOLOGY` retires only the historical C-slot boundary as canonical architecture; it does **not** delete required semantics or evidence.
2. `TRANSFORMED` means the semantic obligation survives under one or more current logical owners in the simplified Foundation/Spine model.
3. `PRESERVED_TRANSFORMED` means strong reusable historical implementation/evidence exists, but current-owner qualification is still required before current completion can be claimed.
4. `DORMANT` means optional/conditional capability retained without creating an always-on mandatory authority. C22 activates only when a selected isolation/risk profile needs it.
5. `STILL_OPEN` is a current implementation/qualification closure statement, not a mapping defect. The 66/66 historical mapping remains closed.
6. `OWNER_GOVERNED` on P-series rows means the compatibility contract is retained, but its success/qualification is adjudicated through the current owner; a port never becomes a semantic truth owner.
7. No September 3 `NOT_EXECUTED` A-01 cell is rewritten by inference. Exact target evidence must bind the exact subject and claim scope.
